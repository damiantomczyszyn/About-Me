O mnieAbout

Programista, który rozumie infrastrukturę A developer who understands the infrastructure

Jestem magistrem informatyki (UMCS, specjalność deweloperska). Od czerwca 2025 r. pracuję jako informatyk w Narodowym Funduszu Zdrowia. W praktyce łączę rolę backend developera i inżyniera platformy: projektuję API w C# (.NET) i interfejsy dla systemów wewnętrznych, zarządzam konfiguracją i wdrażam poprawki na serwerach testowych z Linuksem (RedHat), a przyczyn błędów szukam w logach.

I hold an MSc in Computer Science (UMCS, software development track). Since June 2025 I've worked as an IT specialist at Poland's National Health Fund (NFZ). In practice the role combines backend development and platform work: I design C# (.NET) APIs and interfaces for internal systems, manage configuration and deploy fixes on Linux (RedHat) test servers, and trace bugs through the logs.

Dużą część pracy stanowią dane: piszę skrypty w Pythonie (Pandas, SQLAlchemy), które łączą i weryfikują dane z PostgreSQL, Oracle i DB2, oraz automatyzuję zadania bazodanowe w pgAgent. Dzięki temu powtarzalne, ręczne procesy przestają być ręczne.

A large part of the job is data: I write Python scripts (Pandas, SQLAlchemy) that combine and validate data from PostgreSQL, Oracle and DB2, and I automate database jobs with pgAgent, so that repetitive manual processes stop being manual.

Po pracy utrzymuję homelab: domenę Active Directory na Windows Server, uruchomioną na Proxmox VE i spiętą siecią Tailscale. Bezpieczeństwo IT rozwijam na szkoleniach Securitum (sekurak). Wcześniej programowałem w Javie (Spring Boot) oraz w C/C++ dla mikrokontrolerów, co widać w projektach poniżej.

Outside work I run a homelab: an Active Directory domain on Windows Server, hosted on Proxmox VE and connected with Tailscale. I build my security skills through Securitum (sekurak) trainings. Before .NET I wrote Java (Spring Boot) and C/C++ for microcontrollers, which you can see in the projects below.

    OCR oparty na sieciach neuronowychNeural-network OCR engine

    Silnik rozpoznawania tekstu drukowanego w Pythonie, złożony z trzech sieci neuronowych. A Python engine for recognising printed text, built from three neural networks.

    • Dwie sieci U-Net dzielą stronę na linie i wyrazy, a sieć CRNN (CNN + dwukierunkowy LSTM, funkcja straty CTC) rozpoznaje słowa. Segmentacja bazuje na otwartej implementacji cytowanej w pracy.
    • Trening CRNN na 4 mln syntetycznych obrazów słów, z własnym generatorem wsadów i rozbudowanym generatorem danych.
    • Porównanie z Tesseract 5.1 na ręcznie opisanych zbiorach testowych (teksty z PDF i skany) oraz analiza źródeł błędów.
    • Two U-Nets split the page into lines and words, and a CRNN (CNN + bidirectional LSTM, CTC loss) recognises the words. The segmentation builds on an open-source implementation cited in the thesis.
    • The CRNN was trained on 4 million synthetic word images, using my own batch generator and an extended data generator.
    • Benchmarked against Tesseract 5.1 on hand-annotated test sets (PDF text and scans), with an analysis of error sources.

    • Decyzję podejmuje ważone drzewo decyzyjne oparte na 9 kryteriach, m.in. opadach, wilgotności gleby i prawdopodobieństwie deszczu.

    • Combines the Visual Crossing forecast API with readings from my own weather station (BME280, DHT22, rain sensor), served over HTTP as JSON.
    • A weighted decision tree with 9 criteria, such as rainfall, soil moisture and rain probability, makes the call.
    • The algorithm was tested on 151 days of historical weather data, served by a local Python server and scored by a script.
