O mnieAbout

Programista, który rozumie infrastrukturę A developer who understands the infrastructure

Jestem magistrem informatyki (UMCS, specjalizacja programistyczna). Od czerwca 2025 r. pracuję w Narodowym Funduszu Zdrowia jako informatyk. W praktyce łączę rolę backend developera i inżyniera platformy: piszę kod w C# (.NET), a potem sam konfiguruję i wdrażam poprawki na serwerach testowych z Linuksem (RedHat) i szukam przyczyn błędów w logach.

I hold an MSc in Computer Science (UMCS, software development track). Since June 2025 I've worked at Poland's National Health Fund (NFZ). In practice the role combines backend development and platform work: I write C# (.NET) code, then configure and deploy fixes on Linux (RedHat) test servers myself and trace bugs through the logs.

Dużą część pracy stanowią dane: piszę skrypty w Pythonie (Pandas, SQLAlchemy), które łączą i weryfikują dane z PostgreSQL, Oracle i DB2, oraz automatyzuję zadania bazodanowe w pgAgent. Dzięki temu powtarzalne, ręczne procesy przestają być ręczne.

A large part of the job is data: I write Python scripts (Pandas, SQLAlchemy) that combine and validate data from PostgreSQL, Oracle and DB2, and I automate database jobs with pgAgent, so that repetitive manual processes stop being manual.

Po pracy utrzymuję homelab: domenę Active Directory na Windows Server, uruchomioną na Proxmox VE i spiętą siecią Tailscale. Bezpieczeństwo IT rozwijam na szkoleniach Sekuraka i Securitum. Wcześniej programowałem w Javie (Spring Boot) oraz w C/C++ dla mikrokontrolerów, co widać w projektach poniżej.

Outside work I run a homelab: an Active Directory domain on Windows Server, hosted on Proxmox VE and connected with Tailscale. I build my security skills through Sekurak and Securitum trainings. Before .NET I wrote Java (Spring Boot) and C/C++ for microcontrollers, which you can see in the projects below.
